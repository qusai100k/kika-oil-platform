# قائمة محتوى وقرارات العمل المطلوبة

## طريقة التسليم والاعتماد

لكل عنصر: مالك، مصدر، حالة (مسودة/قيد المراجعة/معتمد)، تاريخ اعتماد، تاريخ مراجعة تالٍ، واللغات. لا يُنشر المحتوى الطبي/المنتجي الحساس بوصفه حقيقة حتى يعتمد.

## الهوية والعلامة

- [ ] الاسم القانوني والتجاري بالعربية والإنجليزية.
- [ ] شعار بصيغ أصلية، لوحة ألوان، خطوط وحقوق استخدامها.
- [ ] قصة العلامة ونبرة الكتابة وقواعد الصور.
- [ ] الهاتف والبريد والعنوان وساعات الدعم وروابط التواصل.

## ملف كل منتج/متغير

- [ ] الاسم، SKU، الفئة، الحجم/الوحدة، السعر والضريبة والمخزون.
- [ ] صور أصلية وحقوقها ونص بديل.
- [ ] قائمة المكونات وتسمياتها ومصدرها.
- [ ] فوائد/ادعاءات موثقة مع جهة الاعتماد.
- [ ] طريقة وكمية وتكرار الاستخدام والتخزين والصلاحية/رقم الدفعة عند الحاجة.
- [ ] التحذيرات والحساسية وموانع الاستخدام والتداخلات وما لا يُجمع معه.
- [ ] أنواع البشرة والمخاوف المناسبة وغير المناسبة.
- [ ] بيانات التصنيع/التنظيم المتاحة.
- [ ] سياسة المنتج المخصص، ووقت التحضير وإعادة الطلب والإرجاع.

## قواعد التقييم والتوصية

- [ ] بنك الأسئلة وخيارات الإجابة وسبب جمع كل حقل.
- [ ] تعريفات أنواع البشرة والمخاوف بلا لغة تشخيصية.
- [ ] مصفوفة توافق واستبعاد المنتج/المكونات.
- [ ] قواعد الحساسية والأدوية والحمل/الرضاعة والفئات الضعيفة.
- [ ] قواعد الإحالة ودرجة الاستعجال ورسالة كل حالة.
- [ ] تفسير معتمد لكل سبب توصية وتحذير واستعمال.
- [ ] حالات اختبار نموذجية ونتيجتها المتوقعة واعتماد المختص.
- [ ] مالك القواعد ودورة المراجعة والإصدارات.

## التجارة والتشغيل

- [ ] الدول والعملة والضرائب وطرق الدفع.
- [ ] مناطق ورسوم ومدة الشحن والناقل والتتبع.
- [ ] حالات الطلب وتعريف انتقالاتها ومسؤول كل انتقال.
- [ ] سياسات الإلغاء والإرجاع والاستبدال والاسترداد والمنتج المخصص.
- [ ] كوبونات مسموحة وقواعد الجمع والانتهاء.
- [ ] آلية تأكيد التحويل اليدوي/الدفع عند الاستلام ومكافحة الاحتيال.

## المختصون

- [ ] الاسم والصورة والسيرة والتخصص والمؤهلات وجهة/تاريخ التحقق والانتهاء.
- [ ] السعر والمدة والتوافر والمنطقة الزمنية والقناة.
- [ ] سياسات الإلغاء والغياب والاسترداد والتأخير.
- [ ] نطاق الخدمة وحدودها ونص عدم الطوارئ.
- [ ] نموذج الموافقة على مشاركة التقييم وسياسة الملاحظات الخاصة.

## الصفحات والنصوص العامة

- [ ] الرئيسية، من نحن، الأسئلة الشائعة، التواصل.
- [ ] الخصوصية والشروط وملفات الارتباط.
- [ ] الشحن والإرجاع والاسترداد والإلغاء.
- [ ] إخلاء مسؤولية المنتج والتوصية والاستشارة والذكاء الاصطناعي.
- [ ] رسائل الموافقة، الأخطاء، الفراغ، النجاح، البريد والتنبيهات.
- [ ] نصوص SEO وعناوين ومشاركة اجتماعية.

## الإدارة والتحليلات

- [ ] مصفوفة الأدوار والصلاحيات وفصل المهام.
- [ ] أحداث التدقيق المطلوبة ومدد حفظها.
- [ ] تعريف كل مؤشر أعمال، من يراه، والفترة الزمنية.
- [ ] قواعد الموافقة على التسويق والمراجعات واستخدام الشهادات.

## أصول الإطلاق

- [ ] النطاق وملكية الحسابات وحسابات المزودين.
- [ ] جهات اتصال الدعم والحوادث والخصوصية.
- [ ] بيانات تجريبية منفصلة وغير حقيقية.
- [ ] دليل إجراءات الطلب والحجز والاسترداد والحوادث.
- [ ] خطة beta ومعايير النجاح وقائمة المشاركين.

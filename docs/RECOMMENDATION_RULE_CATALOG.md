# Recommendation Rule Catalog

All current rules are provisional development rules.

Hard exclusions:

- Incomplete product readiness.
- No active in-stock variant.
- Skin type not mapped to the product.
- Declared allergy matching a product ingredient.
- Human-review safety flags such as previous reaction, prescription topical use, or pregnancy/breastfeeding.

Soft scoring:

- Skin-type match.
- Concern match.
- Simple-routine match.
- Sensitivity caution.
- Low-stock caution.

Rules require owner and specialist review before commercial use.

# تقرير اختبار المرحلة الثانية

التاريخ: 2026-07-16

## الاختبارات المنفذة

- `npm install`: نجح؛ 6 تنبيهات تبعية عابرة (1 منخفض، 5 متوسطة)، بلا مرتفع أو حرج.
- `npm run test`: نجح؛ ملفان و6 اختبارات للبحث والتصفية والفرز والحالة الفارغة والتحقق من التواصل.
- `npm run lint`: نجح.
- `npm run typecheck`: نجح.
- `npx prisma format`: نجح.
- `npx prisma validate`: نجح.
- `npx prisma generate`: نجح.
- `npm run build`: نجح؛ 24 مسارًا مولدًا.

## فحص المتصفح

اختُبرت الصفحة الرئيسية عند 320×568 و375×667 و390×844 و768×1024 و1024×768 و1440×900. في كل حالة: `lang=ar` و`dir=rtl`، عنوان H1 واحد، ولا تمرير أفقي. ظهر تنقل الهاتف حتى 768px وتنقل سطح المكتب عند 1024px و1440px.

اختبار الكتالوج: البحث عن «المساء» أعاد منتجين وكتب الاستعلام في URL؛ بحث غير مطابق أظهر الحالة الفارغة؛ «مسح الكل» أعاد المنتجات الستة. نموذج التواصل قَبِل بيانات صالحة وأظهر حالة `status` تؤكد التحقق المحلي وعدم الإرسال الخارجي.

## فحص لوحة المفاتيح وإتاحة الوصول

تمت مراجعة ترتيب DOM، الروابط والأزرار الأصلية، التسميات، حالة `aria-live`، رابط التخطي، مؤشرات `:focus-visible`، أهداف اللمس وقائمة الهاتف الأصلية. تعذر توثيق تسلسل Tab الكامل آليًا داخل غلاف المتصفح المدمج؛ لذلك لا يُدّعى اجتياز يدوي كامل، ويظل تكراره في Chrome فعلي قبل الإطلاق بندًا مفتوحًا.

## القيد المعروف

لم تُشغّل migration/seed لأن بيانات اعتماد PostgreSQL المحلية غير صالحة (P1000 سابقًا). لم يلزم ذلك لاختبارات المتجر العامة.

# خريطة محتوى المتجر

| المجال | المصدر الرئيسي | المستهلكون |
|---|---|---|
| النصوص العامة والقنوات | `src/constants/content.ts` | الترويسة، التذييل، الصفحة الرئيسية، التواصل |
| المنتجات والفئات | `src/constants/content.ts` | الرئيسية، الكتالوج، التفاصيل، sitemap |
| الأسئلة الشائعة | `src/constants/content.ts` | الرئيسية، FAQ، تفاصيل المنتج |
| القيم والمراجعات الخيالية | `src/constants/content.ts` | الرئيسية، About |
| التصفية والفرز | `src/lib/product-filter.ts` | `Catalog` والاختبارات |
| السياسات | ملفات المسارات العامة و`PolicyPage` | صفحات السياسة والتذييل |

كل قيمة تجارية تحتاج اعتمادًا يجب استبدالها من هذا المصدر المركزي أو نقلها لاحقًا إلى CMS، لا نسخها داخل مكونات العرض.

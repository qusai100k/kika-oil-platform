# تأسيس SEO في المرحلة الثانية

- عناوين وأوصاف عربية خاصة بالصفحات والمنتجات.
- Open Graph على الصفحات الرئيسية وصفحات المنتج.
- sitemap يشمل المنتجات والسياسات الجديدة، وrobots قابل للمراجعة.
- عنوان H1 واحد وبنية عناوين دلالية.
- Breadcrumb JSON-LD آمن في صفحات المنتج.
- لم يُضف Product JSON-LD كي لا تُنشر أسعار أو توفر أو هوية تجريبية كبيانات تجارية حقيقية.
- المسارات ثابتة وقابلة لإضافة canonical عند اعتماد النطاق النهائي.
- لا ادعاءات علاجية في البيانات الوصفية.

قبل الإنتاج: اعتماد النطاق، الاسم، OG image، الأسعار/العملة، سياسة الفهرسة، وربط أدوات مشرفي المواقع.

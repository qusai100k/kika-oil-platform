# Recommendation Explanation Guide

Explanations use deterministic fragments from score contributions and safe notices.

Allowed language:

- يتوافق مع نوع البشرة الذي اخترتِه.
- يرتبط بالاهتمام الذي حددتِه.
- يحتاج الاستخدام النهائي إلى مراجعة المكونات والتعليمات المعتمدة.
- لا تمثل هذه النتيجة تشخيصًا طبيًا ولا ضمانًا للملاءمة.

Avoid:

- سيعالج
- سيشفي
- مضمون
- الأفضل طبيًا
- مناسب 100%
- نتيجة مؤكدة

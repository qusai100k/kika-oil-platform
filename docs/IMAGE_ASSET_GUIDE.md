# دليل أصول الصور

- المصدر الحالي: صورتان تجريبيتان مولدتان خصيصًا للمشروع، محليتان في `public/images`.
- نمط التوليد: عبوات كهرمانية بلا علامة، عاجي/رملي/بني، ضوء استوديو هادئ، نبات جاف، بلا نص أو أشخاص أو ادعاءات.
- الصورة الرئيسية بنسبة أفقية؛ صورة المنتج مربعة وتُعاد قصها عبر `object-position` للتنويع التجريبي.
- العرض يتم بـ`next/image` مع `sizes` وalt عربي؛ يجب تجنب الروابط الخارجية غير المستقرة.
- عند الاستبدال: WebP/AVIF للصور الفوتوغرافية، SVG للرسوم، sRGB، ونسخ 1x/2x مناسبة. لا تُرفع ملفات أصلية ضخمة بلا حاجة.
- لا تستخدم صور Instagram أو صور عملاء أو قبل/بعد دون إذن مكتوب واضح.
- وثّق لكل أصل: المالك، الترخيص، تاريخ الموافقة، alt، نقطة القص، تاريخ الانتهاء إن وُجد.

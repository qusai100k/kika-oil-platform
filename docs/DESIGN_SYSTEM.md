# Design System

## Direction

Temporary premium skincare identity: cream and paper surfaces, warm beige, muted gold, dark brown, soft rose/sage accents. It is calm and feminine without relying on childish decoration. Brand assets remain provisional.

## Tokens

- Colors: `--cream`, `--paper`, `--sand`, `--sand-deep`, `--gold`, `--brown`, `--brown-soft`, semantic success/error.
- Radius: small 0.65rem, medium 1rem, large 1.6rem, pill controls.
- Shadows: restrained surface and feature shadows.
- Container: max 76rem with responsive inline gutters.
- Section rhythm: fluid 4–7rem vertical spacing.
- Typography: system Arabic body fallback; serif display fallback pending licensed brand font.

## Interaction/accessibility

Semantic controls, associated labels, `aria-invalid`/live status, visible `:focus-visible`, disabled state, reduced-motion support, RTL root semantics, logical inline/block CSS, keyboard-capable native dialog/details, and layouts from 320 CSS px.

## Components

Button, Input, Textarea, Select, Checkbox, RadioGroup, Label, FormField, Card, Badge, Alert, Dialog, Dropdown, Skeleton, Spinner, EmptyState, ErrorState, SuccessMessage, PageContainer, SectionHeading, Breadcrumb, ProductCard, PriceDisplay, and ResponsiveImage placeholder.

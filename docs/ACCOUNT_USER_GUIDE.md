# Account User Guide

- Create an account at `/register`, accepting the published terms and privacy policy.
- Sign in at `/login`; protected links return to the intended account destination.
- Update name and phone under **الملف الشخصي**. Email changes are deferred until re-authentication is designed.
- Add, default, and delete delivery addresses under **العناوين**.
- Change the password and revoke other sessions under **الأمان**.
- Orders, assessments, recommendations, consultations, and preferences are truthful protected placeholders for later phases.
